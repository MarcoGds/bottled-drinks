## Projeto: Bottled Drinks - Loja de Bebidas Artesanais ##

## Sobre o Projeto ##
Este é um projeto acadêmico de um e-commerce voltado para a venda de bebidas artesanais engarrafadas. O sistema foi construído do zero com o objetivo de aplicar conhecimentos full-stack. O desenvolvimento está sendo realizado em 4 etapas ao longo do semestre, com entregas mensais incrementais, simulando o ciclo de vida de um produto real de software.

## Tecnologias Utilizadas ##
A aplicação foi desenvolvida utilizando as seguintes tecnologias: React para o frontend, Java com Spring Boot para o backend, banco de dados PostgreSQL e hospedagem na nuvem pelo Render.

## Como Executar Localmente ##
Para rodar este projeto, você precisará ter o Node.js, Java e o Maven instalados na sua máquina.

Primeiro, faça o clone do repositório.

Para rodar o backend, acesse a pasta principal do Java, configure suas credenciais do banco de dados no arquivo de propriedades e inicie a aplicação.</br>
- mvn spring-boot:run

Para rodar o frontend, acesse a pasta do React, instale as dependências usando seu terminal e inicie o servidor local.
- npm start
